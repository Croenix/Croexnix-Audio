# Croenix Audio Assets

This directory contains app assets:

- `images/` - PNG/JPG images (album art, logos, etc.)
- `animations/` - Lottie JSON animations
- `icons/` - Custom icons and graphics
- `fonts/` - Custom fonts (Inter family referenced in pubspec.yaml)

## Fonts (Optional)

The app references Inter font family. You can:

1. **Download Inter fonts** from: https://fonts.google.com/specimen/Inter
   - Place .ttf files here with these names:
     - Inter-Regular.ttf
     - Inter-Medium.ttf
     - Inter-SemiBold.ttf
     - Inter-Bold.ttf

2. **Or use system fonts** (recommended for now)
   - Comment out the fonts section in `pubspec.yaml`
   - App will use default system fonts
